# 精灵资料展示页

《洛克王国：世界》的精灵图鉴与公开配队参考。

**[打开图鉴](https://pacific-shark.github.io/roco-encyclopedia/)**

- 查编号、立绘、种族值、特性、进化关系与技能池。
- 按图鉴编号排列，展示 205 个编号下的 260 个最高阶普通形态；地区及不同外观形态分别列出，首领化不单独列入列表。
- 十八系各有配色与背景，种族值采用六维图，技能池支持分类、搜索与滚动查看。
- 点击「精灵列表」，按名称、编号和属性快速查找；进化链保留中间形态。
- 切换配队，点击六人头像查看该队的配招、性格、血脉、天分方向与整队共鸣。
- 支持手机浏览，链接保留当前精灵、队伍与队员。

## 当前内容

资料来自 2026 年 10 月 20 日读取的 BWIKI 社区快照，包含具体来源与修订号。社区记录可能存在遗漏或更新延迟，不能等同于正式服数据认证。

目前收录三套公开案例：电环水队配置已转录，水鲨队、纯血雨天队仅确认六人名单，其余显示「待补录」。案例不是算法推荐，不提供未经验证的胜率或「最强」结论。

## 仓库内容

这是 GitHub Pages 的静态发布仓库，保存网页、公开图鉴 JSON、网页使用的图片与字体。BWIKI 公开图片转为 WebP 并保留原始像素尺寸，来源地址见 `design-preview/asset-sources.json`。没有训练文件、研究报告、数据库或服务器接口。

使用浏览器访问上方网站即可。运行本地副本时，请用静态 HTTP 服务打开目录，避免直接双击 HTML 导致数据请求失败。
